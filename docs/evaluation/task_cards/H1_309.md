# H1: task 309 — single URL 경로 템플릿 단축 (RET)

**Type**: RETRIEVE
**Source**: WebArena-Verified task 309
**Round**: 2 (Round 1의 H2/102가 NAV 다중-hop 단축 확증한 뒤, RET task type에서의 H 일반화 검증용)

## Intent
> Get the username(s) of the user(s) with the most commits to the thoughtbot/administrate project

Start URL: `http://localhost:8023`

## Hypothesis
KG에 `project/contributor_graph` 클래스가 매핑되어 있고 URL 경로 템플릿은 `/{namespace}/{project}/-/graphs/{branch}` (확인됨). KG는 *경로 구조*만 노출하고, namespace/project/branch의 *구체값*은 agent가 task와 페이지 상호작용에서 직접 추출한다.

V1은 contributor graph 페이지가 존재한다는 KG의 *방향* 정보를 받고 placeholder를 task의 "thoughtbot/administrate"와 default branch 추정값으로 채워 `goto`. branch가 잘못 추정되면 redirect나 404 단서를 보고 정정. V0는 KG 안내 없이 프로젝트 진입 후 사이드바·메뉴를 탐색하여 contributor 페이지를 발견해야 하므로 더 많은 step.

## Predicted V0
- step 1: explore에서 thoughtbot/administrate 검색 또는 dashboard에서 클릭.
- step 2~4: 프로젝트 메인 → "Repository" / "Project Information" 메뉴 탐색.
- step 5~6: Contributors / Graphs 항목 발견·진입.
- step 7 전후: 상단 기여자 식별 → report_success(answer=...).
- 예상 step 수: 6~8

## Predicted V1
- step 1: KG 힌트가 contributor graph 경로 템플릿을 노출. agent는 namespace=thoughtbot, project=administrate를 task에서 추출, branch는 main으로 추정해 `goto`.
- step 2 (필요 시): 잘못된 branch면 redirect / 404 관측 후 master로 재시도, 또는 페이지 default branch 단서 발견.
- step 3 전후: contributor 페이지 도달 → 상위 사용자명 식별 → report_success.
- 예상 step 수: 2~4

## Mechanism invocation signal (V1 log)
- `[KG] inferred target=project/contributor_graph` 합의 K/K
- agent thought 또는 `goto` 호출에 `/-/graphs/` 경로 등장
- HAR에 `/thoughtbot/administrate/-/graphs/...` GET 요청

## Falsification criterion
- V1의 step 수가 V0보다 *같거나 많음*, **and**
- V1 thought에 KG가 노출한 contributor graph 경로 인용 *없음*

→ 두 조건이 모두 성립하면 H1은 본 task에서 refuted.

## Notes
- KG 매핑 확인됨 (phase 0 grep): `project/contributor_graph` → `/{namespace}/{project}/-/graphs/{branch}`.
- branch 변수의 실제 default가 main인지 master인지 task별로 다름. agent가 1회 잘못 추정하면 step이 1 추가될 수 있음 — 이는 KG의 한계가 아니라 *구체값을 agent가 찾는다*는 design principle의 자연스러운 비용.
- L3 (308)과 동일 archetype이지만 평가기 strict-match 결함 task로 분리. H1과 L3의 V1 trial 결과가 step·KG fired 측면에서 유사해야 분리 logic이 성립.
