## Intent
> Go to the merge requests assigned to me

Start URL: `http://localhost:8023`

## Hypothesis
"Merge requests assigned to me"는 두 가능 범위가 있다: (a) 사용자 dashboard scope의 `/dashboard/merge_requests?assignee_username=<me>`, (b) 특정 project scope의 `/{namespace}/{project}/-/merge_requests?assignee_username=<me>`. 본 task는 (a)가 정답. KG의 트리거 문구 분석은 dashboard scope을 인지해 `dashboard/merge_request_list` 클래스로 라우팅한다. V1은 dashboard 사이드바의 "Assigned to you N" 카운트 뱃지 항목을 KG 힌트로 인지해 1-step 클릭으로 도달.
