## Intent
> Invite Abishek and Vinta as collaborator(s) to a11yproject.com repo

Start URL: `http://localhost:8023`

## Hypothesis
KG는 ARIA 표준 기반 수집기로 빌드되었다. GitLab의 "Invite members" 다이얼로그는 Vue Pajamas 컴포넌트로 비-ARIA-conformant이며 내부 입력(사용자 검색, 역할 선택, 만료일)이 KG의 modal_structures에 *비어 있다*. KG은 KG의 페이지 내 컨트롤 카탈로그를 통해 "Invite members" 트리거 버튼까지는 정확히 도달하지만, 다이얼로그가 열린 후의 입력 단계는 KG가 줄 정보가 없어 baseline와 동일한 DOM 탐색으로 회귀. 즉 KG 기여는 *다이얼로그 진입 직전까지*로 한정된다.

## Predicted baseline
- step 1~3: 프로젝트 도달 → Members 페이지 진입.
- step 4: "Invite members" 버튼 클릭 → 다이얼로그 열림.
- step 5~N: 사용자 검색 입력에 "Abishek" 입력 시도, 비ARIA 컴포넌트로 실패·재시도 반복.
- 예상 step 수: 8~20 또는 timeout

## Predicted KG
- step 1~2: KG 힌트가 members 페이지 단축 노출. 에이전트가 직접 진입 (baseline보다 1~2 step 빠를 수 있음).
- step 3: "Invite members" 버튼 클릭 → 다이얼로그 열림.
- step 4~N: 다이얼로그 내부에서 KG 정보 없음 → baseline와 동일 패턴으로 실패·재시도.
- 예상 step 수: baseline와 비슷한 후반 패턴, 다만 진입까지 1~2 step 단축
